
# SmartSaver: Expense Tracker

SmartSaver is a simple web-based expense tracker that helps users manage their finances, track income, and monitor expenses. It offers an intuitive interface for adding transactions, categorizing them, and viewing a detailed transaction history.

## Features

- **Track Income and Expenses**: Add income or expense transactions with description, amount, category, and date.
- **Categories**: Organize transactions by categories such as Salary, Freelance, Healthcare, Food, etc.
- **Currency Support**: Support for different currencies (USD, INR, EUR, GBP).
- **Payment Methods**: Select payment methods like Credit, Debit, Cash, or Bank Transfer.
- **Recurring Transactions**: Mark transactions as recurring for easy management.
- **Transaction History**: View a detailed list of all transactions.
- **Balance Calculation**: See your current income, expenses, and balance.
- **Budgeting Tip**: The app suggests the 50/30/20 rule for budgeting (50% Needs, 30% Wants, 20% Savings).

## Tech Stack

- **Backend**: Python (Flask)
- **Frontend**: HTML, CSS
- **Database**: In-memory storage (can be extended to use a database like SQLite or MongoDB)
- **Version Control**: Git, GitHub

## Installation

### Prerequisites

- Python 3.x
- pip (Python package manager)

### Setup

1. Clone this repository to your local machine:

   ```bash
   git clone https://github.com/your-username/SmartSaver-Expense-Tracker.git
   cd SmartSaver-Expense-Tracker
   ```

2. Install the required dependencies:

   ```bash
   pip install -r requirements.txt
   ```

3. Run the Flask development server:

   ```bash
   python app.py
   ```

4. Open your browser and go to `http://127.0.0.1:5000` to view the app.

## Usage

- Visit the homepage to view the current balance, income, and expenses.
- Use the "Add a Transaction" form to add income or expense entries.
- View your transaction history and track your spending.
